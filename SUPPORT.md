## 🐛 Bug Reports

Found a bug? Please open a [GitHub Issue](https://github.com/AI-Musical-Therapy/platform/issues/new?template=bug_report.md) using the bug report template.

**Before reporting:**
1. Search existing issues to avoid duplicates
2. Try to reproduce the issue with the latest version
3. Include detailed reproduction steps

---

## 💡 Feature Requests

Have an idea for a new feature? Open a [Feature Request](https://github.com/AI-Musical-Therapy/platform/issues/new?template=feature_request.md).

**Guidelines:**
- Check the [Roadmap](ROADMAP.md) to see if it's already planned
- Clearly describe the use case and benefit
- Consider if it aligns with the project's goals
