## 6. GitHub Actions

- **CI Pipeline** (`.github/workflows/ci.yml`): Lint, test, build, security scan on every PR
- **Dependabot** (`.github/dependabot.yml`): Automated dependency updates for npm, pip, GitHub Actions, Docker
